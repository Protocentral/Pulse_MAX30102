# Hardware — v3 (archived)

The Eagle design files in this folder (`pc_pulse_v3.sch`, `pc_pulse_v3.brd`,
`pc_pulse_v3.pdf`) are the **v3** revision of the ProtoCentral Pulse board.

They are kept here permanently so that existing links, forks, and references to
these files continue to work. They are no longer the current design.

## Current design files

Revision **v4** and everything that follows it live in a dedicated hardware
repository, as KiCad projects:
